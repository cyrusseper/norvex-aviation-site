# Norvex Aviation Site

Standalone Next.js marketing site for Norvex Aviation.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Check

```bash
npm run lint
npm run build
```

## Project Structure

```text
src/app
src/components
src/components/layout
src/components/sections
src/lib
public
```
